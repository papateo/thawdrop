Thawdrop

Share files and folders straight from your computer with a link or QR code. No upload, no server storage, no size limit — the file goes directly from your device to theirs.

Download for Mac Apple Silicon
Received a Thawdrop link? Just open it in this browser — nothing to install. The sender needs the desktop app; the receiver only needs a browser.

How it works

Four steps, and the file never sits on someone else's server.

1

Pick a file or folder

In the desktop app, drop it in, browse for it, or right-click it and choose “Share with Thawdrop”. Optionally add a password, an expiry time, or a download limit.

2

Get a link and QR code

The app starts sharing straight from your disk and turns it into a magnet link, shown as a link and a QR code. Nothing is uploaded anywhere.

3

They open the link

The receiver opens it in any browser, sees the name and size (or a folder they can browse), and picks what to download.

4

Direct transfer

The browser connects to your computer peer-to-peer (WebRTC) and pulls only what was chosen. Keep the app open until they're done.

  • The link is a magnet link. It's the same kind of link BitTorrent uses: it identifies what is being shared and how to find the sender, but contains no file data. Thawdrop wraps it as thawdrop.com/#magnet:?…, so the address sits after the #, which browsers never send to a server.
  • The link is the key. Anyone who has it can download, so treat it (and the QR code) like a password — or add a real password on top.
  • Folders are browsable. Receivers see the file tree and download individual files — unchosen files are never transferred.
  • Password shares are encrypted in the sender's app (AES-GCM) before sharing. The password is never in the link, so send it separately.
  • Sharing ends when you want. Stop it manually, let it expire, or cap the number of downloads.

Where Thawdrop is stronger

  • Private: files never pass through or rest on a server.
  • No size limit and no waiting for an upload to finish.
  • Receivers only need a browser, and can pick just the files they want.
  • Optional password encryption, expiry and download limits.
  • Works across networks, not just between nearby devices.

Where others are better

  • Cloud tools let the sender close their laptop — Thawdrop needs the sender online until the transfer ends.
  • Built-in tools like AirDrop are faster to reach and need no setup for nearby devices.
  • Strict corporate or campus networks can block direct connections unless a relay is available.
  • Thawdrop is new, so it's less familiar than the big names.
